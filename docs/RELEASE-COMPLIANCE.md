# Checklist jurídico e de release

Este checklist é operacional e não substitui aconselhamento jurídico.

## Antes de uma distribuição institucional

- [ ] Confirmar titularidade e autorização de todos os arquivos do projeto.
- [ ] Confirmar que a release pública contém o código-fonte correspondente aos binários.
- [ ] Criar tag assinada com a mesma versão dos instaladores.
- [ ] Revisar `LICENSE` e `THIRD-PARTY-NOTICES.md`.
- [ ] Arquivar licenças e fontes correspondentes dos componentes incorporados.
- [ ] Confirmar conformidade AGPL do Ghostscript ou licença comercial válida.
- [ ] Confirmar qualificação/licença vigente do ImageSharp.
- [ ] Gerar SBOM e hashes SHA-256.
- [ ] Testar instalação e desinstalação em sistemas limpos.
- [ ] Verificar ausência de credenciais, dados pessoais e arquivos internos.
- [ ] Submeter o conjunto a revisão jurídica da instituição ou profissional habilitado.
