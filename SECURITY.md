# Política de segurança

## Versões suportadas

Somente a versão mais recente publicada recebe correções de segurança.

## Como relatar

Não publique detalhes de uma vulnerabilidade ainda não corrigida em uma issue pública.

Quando o repositório público estiver disponível, utilize o recurso **Report a vulnerability** na aba **Security**. Inclua:

- versão do aplicativo;
- sistema operacional;
- passos mínimos para reproduzir;
- impacto observado;
- arquivo de teste sem informações pessoais, quando indispensável.

## Escopo de privacidade

O Compress my Web processa arquivos localmente e não contém telemetria. Relatórios de erro e arquivos só devem ser compartilhados voluntariamente pelo usuário.

## Dependências

Vulnerabilidades em ImageSharp, qpdf, Ghostscript, Avalonia ou .NET devem ser avaliadas também nos canais de segurança dos respectivos projetos.
